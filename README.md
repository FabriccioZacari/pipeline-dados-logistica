# 📦 Pipeline de Dados End-to-End: Logística e Operações (Python + Power BI)

## 📌 Visão Geral do Projeto
Este projeto simula um pipeline analítico de ponta a ponta (*End-to-End*) voltado para o setor de **Logística e Cadeia de Suprimentos (Supply Chain)**. O objetivo é automatizar o tratamento de dados brutos de transporte, calcular indicadores críticos de desempenho e entregar um painel executivo para suporte à tomada de decisão gerencial.

---

## 🛠️ Arquitetura e Fluxo do Pipeline
O projeto foi desenvolvido seguindo as melhores práticas de mercado em três etapas integradas:
1. **Geração & Ingestão:** Simulação e captura de dados operacionais brutos de entregas.
2. **Engenharia & Tratamento (Python / Pandas):** Limpeza, estruturação de dados, tratamento de nulos e criação de regras de negócio automatizadas (como cálculo de dias de atraso e custo por quilo).
3. **Business Intelligence (Power BI):** Modelagem de dados e construção de um dashboard executivo focado em KPIs logísticos.

---

## 📊 Principais Indicadores (KPIs) Analisados
- **% OTD (On-Time Delivery):** Percentual de entregas realizadas dentro do prazo previsto.
- **Custo Total de Frete:** Métrica financeira consolidada por transportadora e região.
- **Volume de Pedidos:** Acompanhamento de entregas bem-sucedidas, atrasadas e extraviadas.
- **Eficiência por Transportadora:** Comparativo de custos e prazos entre os parceiros logísticos.

---

## 💻 Tecnologias e Ferramentas Utilizadas
- **Python 3 / Google Colab:** Manipulação e tratamento de dados com a biblioteca `Pandas`.
- **Power BI Desktop:** Modelagem de dados, medidas em DAX e visualização executiva.
- **Git & GitHub:** Versionamento de código e documentação técnica do portfólio.
